# 接口契约与失败验证；在对应验证或交付场景下使用。

围绕接口可观察行为验证：输入边界、未认证/无权限、资源不存在、重复请求、部分失败与取消。需要事务时检查失败后的数据一致性。
外部副作用使用任务范围内的测试替身或明确许可环境；不能用模拟结果声明真实服务可用。对后台任务分别核对创建回执、实际运行和终态。

执行前调用平台提供的 ensure_role_environment，核对本节点真实执行环境。缺项先准备并复核；安装失败或能力不兼容应返回具体证据，不把注册视为已加载。遵守平台工作区、权限和交付协议。
